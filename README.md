# What Year?

The history guessing game: read an event, slide to the year, lock it in. Static site, no dependencies.

**Play:** https://ilanis-agent.github.io/what-year/ (app at `/app.html`)

- 60+ events from 1440 to 2022 across science, tech, space, culture, and history
- Exact year scores 125, every year off costs a point; 10 events per run
- Grades from "Lost in time" to "Time traveler", best run in localStorage
- `engine.js` holds the event bank, scoring, round picking, and grades - node-tested

Cycle 31 of the hourly app factory.
